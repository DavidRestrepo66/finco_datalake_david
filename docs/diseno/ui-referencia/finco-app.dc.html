No se encontraron los artefactos de dbt

La app busca run_results.json (resultado de las pruebas) y manifest.json (linaje por columna) en la carpeta indicada por DBT_TARGET_DIR. Monta la carpeta target del proyecto dbt como volumen de solo lectura en el servicio de la app:

services:
  app:
    environment:
      DBT_TARGET_DIR: /app/dbt_target
    volumes:
      - ./dbt/target:/app/dbt_target:ro

Después: docker compose run --rm pipeline y docker compose up -d app. Esta página no muestra resultados de pruebas sin esos archivos.
